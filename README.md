# Explore With Me (Микросервисная архитектура)

Это приложение, позволяет пользователям делиться информацией о событиях и находить компанию для участия в них.
Представляет собой декомпозированную на независимые функциональные модули (микросервисы). 
Система спроектирована с учётом высокой отказоустойчивости (паттерн Circuit Breaker).

## Архитектура системы

### Выделенные сервисы

* **gateway-server (Port: 8080)** — Единая точка входа (API Gateway). Отвечает за маршрутизацию внешнего трафика к соответствующим микросервисам.
* **discovery-server (Port: 8761)** — Сервер регистрации и обнаружения сервисов.
* **config-server (Port: 8888)** — Централизованное хранилище конфигураций для всех модулей системы.
* **user-service** — Управление учетными записями пользователей.
* **category-service** — Справочник категорий мероприятий.
* **request-service** — Управление заявками пользователей на участие в событиях.
* **comment-service** — Сервис для публикации, редактирования и администрирования комментариев к событиям.
* **event-service** — Управление мероприятиями и подборками событий. Интегрировано с модулем фиксации статистики.
* **stats-server** — Сервер сбора статистических данных (просмотров).

### ⚙️ Конфигурация системы

Все файлы конфигураций вынесены из кода и централизованно располагаются в модуле **config-server**. 
Настройки маршрутизации API Gateway заданы в application.yml и также располагаются в модуле **config-server**.

### 🔌 Внутренний API (Межсервисное взаимодействие)

Взаимодействие между микросервисами осуществляется в синхронном режиме по протоколу HTTP/REST с использованием клиентов **Spring Cloud OpenFeign**. 
Для предотвращения проблемы каскадных падений все Feign-клиенты защищены фабриками откатов (FallbackFactory) с механизмами **Resilience4j Circuit Breaker** и автоматическими повторами **Retry**.
Все внутренние эндпоинты изолированы и используют префикс /contract:

### 📲 Контракты взаимодействия (Примеры)

* GET /contract/user/usersIds — Пакетный сбор пользователей пачкой по списку ID для исключения проблемы N+1.
* GET /contract/event/eventIds — Пакетный сбор событий по списку ID для комментариев.
* GET /contract/category/categoriesIds — Пакетный сбор категорий.
* GET /contract/request/confirmed — Запрос счетчиков подтвержденных заявок для пачки событий.

### 📖 Внешний API (Спецификация)

Внешний API предоставляет публичные (для гостей), приватные (для авторизованных пользователей) и административные (для модераторов) эндпоинты, доступные через шлюз http://localhost:8080.
Полная спецификация внешнего API со всеми схемами запросов и ответов доступна по ссылке: [Explore With Me — OpenAPI Спецификация](https://raw.githubusercontent.com/yandex-praktikum/java-explore-with-me/main/ewm-main-service-spec.json).
